HashSet resizing___________
->Hash based collections don't keep an unlimited number of elements
in the initial table. As element increases, java resize the table
This improves look up efficiency but resizing itself costs work (This keeps search times 
fast, but the copying step takes extra time and computer memory all at once.)

LoadFactor?...
it determines when resizing should be happen
-> commonly used LoadFactor is 0.75
Conceptually threshold= capacity * loadfactor 
if capacity is 16 then 16*0.75= 12 which is threshold and when table reaches the 
threshold then table resize itself

        Red Black Tree is a self balancing binary search tree where each nodes stores an extra bit to

        for search, insert and delete.
