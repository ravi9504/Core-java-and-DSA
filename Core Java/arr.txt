Do you about the System.arraycopy()?
    Suppose you have an array and you want to copy it into the other array.
    Then you will do this problem by using for loop and copy each element of array to the copied array
    But in java We have built in method that copy the every element of array and that is 
    Now see syntax,
        System.arraycopy(
            source,  // from which array you want to copy       source
            srcPos, //Starting index in source                  0
            Destination, // where we want to copy               Destination
            desPos, // starting index in Destination            0
            length  //number of elements to copy                source.length
        )

        example    copy an array two time in other array
        int arr[]= {23,435,45,6324,342};
        int copy[]=new int[arr.length];
        System.arraycopy(arr,0,copy,0,arr.length)
        System.arraycopy(arr,0,copy,arr.length,length);

Important question why this System.arraycopy() is faster than manual copying
    As we know both has same time Complexity O(n) but in manual looping
        our repeated java level instruction-> array access and loop handling and copy operation 

        whereas in System.arraycopy() is highly optimized by jvm. The jvm can use specialized
        low-level mechanism to copy array memory, and depeing upon array type and runtime situation
this is where constant make factor difference      like A->100n   B-> 5n
as we are seeing both are O(n) but B is much faster than A
